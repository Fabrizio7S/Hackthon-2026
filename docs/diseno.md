# Diseño y referencias

El esquema y las decisiones del equipo guían las funciones. El acabado visual se ajustará después. Campos y botones dibujados no sustituyen reglas de negocio aprobadas.

## Criterios
- Acciones y estados comprensibles para personas con poca experiencia digital.
- Etiquetas visibles, controles legibles y errores con un siguiente paso claro.
- Prioridad móvil, volver y consistencia entre pantallas.
- No fijar librerías, navegación ni estilos por inferencia de las referencias.
